# Customer Churn Prediction using Artificial Neural Network (ANN)

An end-to-end Deep Learning project that predicts whether a customer is likely to churn using TensorFlow and a modular machine learning pipeline.

## Project Overview

Customer churn is one of the biggest challenges for subscription-based and e-commerce businesses.

This project predicts whether a customer is likely to churn using an Artificial Neural Network (ANN) built with TensorFlow.

The project follows a modular production-style architecture including data ingestion, preprocessing, training, evaluation, prediction, and deployment with Streamlit.

## Features

- Modular Project Architecture
- Configuration Management
- Custom Logging
- Exception Handling
- Data Ingestion Pipeline
- Data Preprocessing Pipeline
- ANN Model using TensorFlow
- Model Evaluation
- Prediction Pipeline
- Streamlit Web Application
